Android 落地要点

Isolation 是 纯程序化方案：AGSL RuntimeShader 单 pass 直译这份 fragment shader；封面在 CPU 一次性走 直方图(64×64) → K-Means/八叉树择优 → 4 主色 → OkLab， 以 uniform 上传。无纹理采样、无几何网格，每帧仅一次全屏三角函数，比 Mesh 方案更轻。 换歌 = 重掷随机参数 + 1s OkLab 调色板过渡。API 33+ 可用，旧系统回退静态渐变。
