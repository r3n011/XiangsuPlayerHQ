01 / FEATURES

不只是播放器

播放、歌词、云端、AI —— 每一块都按能长期每天使用的标准来做。

01

绚丽背景

对齐 applemusic-like-lyrics 的网格渐变渲染：32×32 封面纹理揉进双三次 Hermite 网格，随时间旋转、跟低频鼓点呼吸。

02

高保真解码

Media3 ExoPlayer + FFmpeg，加上经 JNI 接入的 miniaudio。原生播放 DSD64 / DFF，支持外置 USB DAC 与 ReplayGain 音量归一化。

03

逐字歌词

网易云 / AMLL / LRCLIB 多源可配优先级，日语罗马音按需下载引擎，另有可拖拽、可贴边收起的悬浮歌词。

04

云端打通

QQ 音乐、网易云、Bilibili、Jellyfin、Navidrome、Telegram、Google Drive —— 统一收敛成同一个媒体库和同一条播放队列。

05

AI 助手

歌单生成、元数据补全、播放列表质量评分。Gemini、DeepSeek、OpenAI、Groq、OpenRouter 都能接。

06

Web 远控

用浏览器控制和查看播放状态、歌词与队列；手机就是音响，电脑就是遥控器。
