## 修复音乐库扫描卡死 + 更新检测逻辑 (PixelPlayer)
- **根因**：`AudioMetadataReader.read()` 使用 `runBlocking { withTimeout(10s) { readInternal() } }` 包裹 native TagLib JNI 调用。但 `readInternal` 是普通函数（非 suspend），`withTimeout` 完全无效——无法中断 native 调用，`runBlocking` 永久阻塞线程。遇到损坏/特殊音频文件时线程泄漏，`Dispatchers.IO` 线程池耗尽，扫描卡死（约350首时卡住，见 debug-media-scan-350-freeze.md）。
- **修复 AudioMetadataReader.kt**：移除 `runBlocking`/`withTimeout`，改用专用线程池（4线程, daemon, MIN_PRIORITY）+ `Future.get(timeout)`。超时后调用方立即释放，native 调用后台继续但不阻塞 IO 线程池。
- **修复 UpdateChecker.kt**：`hasUpdate()` 参数名 `installedTime` → `lastUpdateTime`，注释同步更新。
- **修复 AboutScreen.kt**：移除 `firstInstallTime` 兜底逻辑（`installedTime` 变量），`lastUpdateTime` 获取失败时兜底 `0L`。
- 编译验证通过（`BUILD SUCCESSFUL`）。

## 修复播放卡死 + 展开播放器闪屏 (PixelPlayer)
- **播放卡死根因**：`DualPlayerEngine.tryRecoverFromError` 只处理代理连接错误。当 `StuckPlayerException`（`ERROR_CODE_TIMEOUT=1003`）触发时——audio offload HAL 报告 `STATE_READY + isPlaying=true` 但 position 10秒不前进，Media3 内置 `StuckPlayerDetector` 杀掉播放器——错误走到 `else` 分支只记日志，player 停在 `STATE_IDLE` 不恢复。自定义 offload fallback 只覆盖 BUFFERING 状态（`!isPlaying`），不覆盖 READY 状态卡死。
- **修复 DualPlayerEngine.kt**：在 `tryRecoverFromError` 中插入 `ERROR_CODE_TIMEOUT` 分支：offload 开启则 `disableAudioOffloadForSession` + 重建 player；已禁用则 re-prepare queue。
- **闪屏根因**：`fullPlayerOffset` 在 `ef=0.35` 处硬切，此时 `contentAlpha=13%`，播放器内容突然在 13% 透明度处出现。改为 `0.25`（alpha=0 处）消除闪屏。
- 编译验证通过（`BUILD SUCCESSFUL`）。

## 修复单侧预览(ONE_PEEK)封面无圆角 (PixelPlayer)
- **问题**：全屏播放器开启"单侧预览"（ONE_PEEK，显示当前+下一首封面）后，封面没有圆角。
- **根因**：`MaskRoundedRectShape.createOutline` 依赖 `itemInfo.maskRect`（由 `placeWithLayer` lambda 设置）。`maskRectState` 初始值为 `Rect.Zero`，首次布局前 `placeWithLayer` 未执行时，`Rect.Zero.intersect(layerBounds)` 得到零尺寸矩形，`inflate(0.5f)` 后仅 1px，clip 退化为 1px 矩形导致圆角完全消失。
- **修复1 `RoundedParallaxCarousell.kt`**：`MaskRoundedRectShape.createOutline` 中检查 `rawMask.width <= 0f || rawMask.height <= 0f`，无效时回退到整个 `layerBounds`，确保首次布局前也有正确的圆角 clip。
- **修复2 `AlbumCarouselSelection.kt`**：在 carousel content lambda 中给封面 Box 添加 `.clip(RoundedCornerShape(corner))`（`corner = lerp(36.dp, 15.dp, expansionFraction)`），用 `remember(corner)` 缓存 shape 对象。作为 carousel mask clip 机制的双重保障。
- 编译验证通过（`BUILD SUCCESSFUL`）。

## 修复单侧预览封面缝隙露出+跳变 (PixelPlayer)
- **问题**：上一轮修复（垂直范围限制 + 每帧创建新 shape）导致两个新问题：1) 滑动时左边圆角缝隙露出上一个封面；2) 封面跳变。
- **根因**：1) 垂直范围限制代码修改了 maskRect 的 top/bottom，缩小了 clip 区域，滑动时相邻 item 从缝隙露出；2) 每帧创建新 `MaskedRoundedRectShape` 对象，maskRect 浮点波动导致 outline 跳变。
- **最终方案——双层 clip 分离**：
  - `RoundedParallaxCarousell.kt`：彻底回退破坏性修改。移除垂直范围限制；回到 `shape = clipShape`（共享对象，不每帧重建）；移除 `MaskedRoundedRectShape` 类和 `itemCornerRadius` 参数链；`clipShape` 创建时圆角设为 `0.dp`（纯矩形 clip，负责 carousel 可见区域裁剪）；保留 `MaskRoundedRectShape` 中 maskRect 无效回退到 layerBounds 的逻辑。
  - `AlbumCarouselSelection.kt`：给封面 Box 添加 `.clip(RoundedCornerShape(corner))`（内容层圆角，负责封面圆角显示），用 `remember(corner)` 缓存 shape。
- **为什么有效**：layer clip 是矩形（无圆角）→ 没有圆角缝隙 → 不会露出相邻封面；Box.clip 是圆角矩形 → 封面有圆角；两个 clip 不重叠 → 不会白色角；shape 用 remember 缓存 → 不会跳变。
- 编译验证通过（`BUILD SUCCESSFUL`）。
