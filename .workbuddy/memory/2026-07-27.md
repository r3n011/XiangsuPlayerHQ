## APK 体积分析（PixelPlayer）
用户怀疑 100MB vs 66MB 是 ABI 重复打包/FFmpeg/TDLib 双份导致。实测结论：

- 「100MB」实际是 `app/debug/app-arm64-v8a-debug.apk`(99.2MB)。Release arm64 = 80.5MB，armeabi-v7a = 73.6MB。
- ABI split 已生效：assembleRelease 产出两个独立 APK，无 universal 包。①②③⑤ 怀疑基本不成立。
- 真实体积分布(arm64 release, 80.5MB)：DEX 代码 32.0MB(40%，classes5.dex 单文件 30MB)、原生库 24.5MB(其中 libtdjni.so/TDLib 20.7MB)、kuromoji 词库 com/atilika/kuromoji/ipadic/*.bin ≈12.7MB、res 5.5M、arsc 4.8M、assets 0.3M。
- FFmpeg(libffmpegJNI.so) 仅 1.4MB，不是问题。
- proguard-rules.pro 有包级 `-keep class androidx.compose.** {*;}` 等过宽规则，关掉了 R8 死代码消除，是 DEX 膨胀主因之一。
- 优化建议 P0：去 kuromoji-ipadic(~12.7MB)、收窄 proguard keep；P1：评估 TDLib/Ktor server+Netty/material-icons-extended；P2：发 AAB、放弃 armeabi-v7a、R8 fullMode。
