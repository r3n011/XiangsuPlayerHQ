# 附录B · 隐私政策（像素播放器）

版本：v1.0 · 生效日期：2026-10-24
> 安卓端必须与 iOS 端展示**完全一致**的正文；存储位置按平台适配（见第五节）。

## 一、概述

我们尊重并保护您的个人信息。像素播放器以「本地优先」为原则：您的音乐数据默认仅存储于本机，非您主动操作，不会上传。本政策说明我们在使用本软件过程中会接触到的信息及其处理方式。

## 二、我们处理的信息

1. **本地曲库信息**：为提供音乐播放与管理功能，App 会在您的设备本地建立曲库索引（歌曲标题、艺术家、专辑、时长、歌词、封面等元数据）。该索引仅存储于本机。
2. **播放数据**：播放记录、收藏、最近播放、播放次数等用于在设备本地生成统计与个性化展示，不上传服务器。
3. **插件相关数据**：
   - 插件列表、启用状态、协议同意状态存储于本机；
   - 插件私有 KV 存储按插件隔离，仅存本机；
   - 您在设置页配置的插件服务地址（如 NAS、插件商店 baseURL）存储于本机，用于直连您自选的设备或服务。
4. **网络访问信息**：当您使用多音源、投屏或插件能力时，App 会按您的配置直连相关服务（如您的 NAS、第三方 API 镜像、DLNA 设备），该过程中的请求仅由您与对应服务间完成，我们不经过其中转。
5. **通知权限**：如您允许，App 会申请本地通知权限（用于歌词推送、插件通知提醒等），全部在设备本地完成。

## 三、我们收集的信息

像素播放器本身**不设账号体系、不收集您的身份信息，也不收集您的音乐行为数据**。我们不使用任何第三方统计 SDK 上报您的数据。

## 四、第三方插件与隐私

1. 第三方插件在您授权的能力范围内运行，其读写均受宿主权限模型约束（见《用户协议》第三节）。
2. 插件可能因其自身功能需要（如您主动配置的网络凭据）与第三方服务通信，相关数据由您与插件作者及其服务之间直接交互。
3. 我们对第三方插件的数据处理行为不作承诺，建议您启用前阅读该插件附带的《用户协议与免责声明》。

## 五、数据存储与删除

1. 全部数据存储于您的设备本地：
   - Android：`SharedPreferences` / `DataStore`、应用私有目录 `filesDir`、`cacheDir`；
   - iOS：`UserDefaults`、应用沙盒、Keychain（如涉及登录态）。
2. 卸载 App 或清除数据后，相关本地数据即被删除，我们无法远程读取或恢复。
3. 插件私有数据前缀：`xs.plugin.<pluginId>.`；卸载插件即清除。

## 六、未成年人保护

本软件不面向未成年人定向运营。如您是未成年人，请在监护人指导下使用。

## 七、政策更新

我们可能不时更新本政策，更新后将在 App 内公示。重大变更会显著提示。

## 八、联系我们

如对本政策有任何疑问，请通过 App 内「关于」页面的联系方式与我们取得联系。
