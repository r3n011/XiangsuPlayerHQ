# 平台接口与稳定性风险说明（KI-013）

> 本文档如实记录应用中涉及的国内平台逆向接口与平台特有稳定性问题，作为后续开发、
> 排障与对外沟通的统一参照。策略：**官方开放接口优先，逆向接口仅作功能兜底**，
> 并在接口失效时优先考虑降级体验而非加深逆向程度。

## 一、逆向接口与风控风险（合规提示）

应用为在无官方授权的情况下提供以下平台能力，直接调用或复刻了这些平台的非公开接口。
它们随时可能因平台升级而失效，也可能涉及违反平台用户协议的风险，请知悉：

| 平台 | 逆向点 | 已知风控表现 | 现状与策略 |
|---|---|---|---|
| QQ 音乐 | `media_mid` / `vkey` 取链、`zzeSign` + `getKeyUrlUnsigned` 签名链路 | 返回码异常、签名失效后链接 403 | 保留内置链路兜底；网页端签名不可用时引导用户走换源 |
| 网易云 | EAPI 手机号登录、`wmda`/`eapi` 加密参数、`personal_fm`、`recommend/history`、`homepage/block/page` 等 | `-332` / `-406` 风控码、Geetest 滑块挑战 | 登录优先走 EAPI + 旧 NCM 通道双轨；风控挑战给出明确提示 |
| 酷狗 | 签名 / 设备注册 `dfid` | 登录态校验失败、设备注册被拒 | 失败时提示重新登录，不自动重试加重风控 |
| B 站 | Web 端 WBI 签名、扫码登录 | `-332` / `-406` 风控码 | 二维码轮询已做限频；扫码失败引导重新生成 |
| 落雪/LX 脚本生态 | 聚合第三方 JS 音源（来源为社区脚本） | 各脚本自身风险自负 | 导入时明示来源与权限；运行隔离在独立 QuickJS 实例 |

**接口失效的处理原则**：先查平台是否已开放官方等价接口（如网易云开放平台、B 站公开
API），有则切换官方；否则降级到跨源搜索兜底；最后才考虑跟进逆向协议变更。

## 二、Android 平台特有稳定性问题（历史记录）

以下问题为 Android 音频链路上的平台特有坑，修复与规避记录见 CHANGELOG：

- **AAudio EOS 卡死**：部分机型 `AAudioStream` 在流末尾（EOS）请求不返回，
  导致 stop/flush 挂起。规避：为该路径增加超时与强杀兜底。
- **HAL offload 跳帧**：部分厂商 HAL 的 offload 通道在变速/Seek 时丢帧。
  规避：可关闭「直接输出」优先走普通通道。

## 三、对外口径

- 应用不含账号体系、不收集用户数据；各平台登录凭据仅保存在本机。
- 涉及第三方平台的功能由用户自行承担平台侧协议风险；应用方不对接口可用性作出承诺。
